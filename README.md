## 🔒 어떻게 "우리만" 보나요?

- 앱 주소(GitHub Pages)는 누구나 열 수는 있지만, 안의 데이터는 **AES-256 암호화**되어 있어서 **비밀번호 없이는 아무것도 안 보입니다.** (검색엔진 노출도 차단)
- 부부 정보(통장·소득 등)는 저장소 코드에 없고 **GitHub Secrets**(암호화된 비밀 저장소)에만 들어갑니다. 저장소가 공개여도 Secrets는 소유자 외엔 못 봅니다.
- 실행 로그에는 건수만 찍히고 개인정보는 출력하지 않습니다.
- 알림 기록(`state/state.enc.json`)도 같은 비밀번호로 암호화되어 저장됩니다.

## ⚙️ 처음 설정 (한 번만)

### 1단계 — 공공데이터포털 API 키 받기 (5분, 무료, 자동승인)

1. https://www.data.go.kr 로그인 (네이버/카카오 간편로그인 가능)
2. 검색창에 아래 두 개를 각각 검색 → 들어가서 **[활용신청]**
   | 서비스 이름 | 활용목적 예시 |
   |---|---|
   | **한국부동산원_청약홈 분양정보 조회 서비스** | 개인 청약 일정 알림 (웹 사이트 개발) |
   | **한국토지주택공사_분양임대공고문 조회 서비스** | 개인 청약 일정 알림 (웹 사이트 개발) |
   - 상세기능은 **전부 체크**, 라이선스 동의 → 신청. "개발계정"은 바로 승인됩니다.
3. **마이페이지 → 데이터활용 → Open API → 인증키 발급현황**에서
   **일반 인증키(Decoding)** 를 복사합니다. (Encoding 키를 넣어도 자동으로 처리되지만 Decoding을 권장)
   - ⚠️ 승인 직후 1~2시간은 "SERVICE KEY IS NOT REGISTERED" 오류가 날 수 있어요. 시간이 지나면 자동 해결됩니다.

### 2단계 — GitHub Secrets 넣기

저장소 → **Settings → Secrets and variables → Actions → New repository secret**

| 이름 (정확히) | 넣을 값 | 필수 |
|---|---|---|
| `DATA_GO_KR_KEY` | 1단계의 일반 인증키(Decoding) | ✅ |
| `APP_PASSWORD` | 앱 잠금 비밀번호. 부부가 같이 쓰는 문장 (12자 이상 권장) | ✅ |
| `PROFILE_JSON` | 부부 정보. 앱의 **우리정보 탭 → [JSON 복사]** 로 만든 값을 그대로 붙여넣기 | ✅ |
| `NTFY_TOPIC` | 알림 주제 이름 (남이 추측 못 하는 영문+숫자, 예: `wzcy-8k2m...`) | 알림 원하면 |
| `APP_SALT` | 아무 영문 문자열 (암호화 강화용). **바꾸면 앱에서 비밀번호를 다시 입력** | 선택 |
| `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` | 텔레그램으로도 받고 싶을 때 | 선택 |

> 비밀번호(`APP_PASSWORD`)를 바꾸면 다음 실행부터 새 비밀번호로 열립니다. 이전 알림 기록은 초기화돼요.

## 🗺️ 지도 · 관심 동네

- 지도 탭: 공고 위치를 **초록(가능성 높음) · 노랑(조건 확인) · 주황(혼인신고 후) · 회색(불가)** 점으로 표시, 🏠은 우리 동네(앱 '우리정보'의 사는 동 — 암호화된 정보에만 저장). 점을 누르면 공고 요약 → [자세히 보기].
- 주소는 매일 실행 때 OpenStreetMap(Nominatim)으로 좌표를 찾고, 못 찾으면 동/구 중심에 **옅은 원(대략 위치)** 으로 표시합니다. 찾은 좌표는 암호화된 기록에 저장해 다시 묻지 않아요.
- 관심 동네 정의는 `site/engine.js`의 `AREAS` — 독산·신림은 해당 **동만**, 나머지는 시·구 전체. LH처럼 시·도만 오는 공고는 공고 이름에 동네 이름이 있을 때만, 서울·경기 **광역 매입·전세임대**는 지도 밖 목록으로 보여줍니다.
- 앱 '우리정보'에서 동네 체크를 끄면 그 휴대폰에서 바로 숨겨지고, `PROFILE_JSON`에 넣으면 알림 범위도 바뀝니다.
