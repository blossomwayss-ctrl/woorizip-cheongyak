## 🙋 내 앱 만들기 (처음 한 번, 약 20분)

> 이 저장소를 그대로 쓰는 게 아니라 **내 GitHub에 복사본을 만들어** 내 동네·내 정보·내 비밀번호로 씁니다.
> 원래 주인의 정보는 복사본에 들어가지 않아요(전부 원래 주인의 비밀 저장소와 암호화된 파일에만 있어요).

**준비물**: GitHub 계정(무료) · 공공데이터포털 계정(무료) · 휴대폰

### 1. 내 저장소 만들기
1. 이 저장소 페이지 위쪽 초록 버튼 **[Use this template] → Create a new repository**
2. **Repository name**: 아무거나 (예: `my-cheongyak`)
3. **Public** 선택 → **Create repository**
   - 무료 플랜은 공개 저장소에서만 앱 주소(GitHub Pages)를 켤 수 있어요. 공개여도 코드만 보이고, 내 정보는 아래 Secrets와 암호화된 파일에만 있어요.

### 2. 공공데이터포털 API 키 받기 (무료, 자동승인)
1. https://www.data.go.kr 로그인
2. 아래 두 서비스 페이지에서 각각 **[활용신청]**
   - [한국부동산원_청약홈 분양정보 조회 서비스](https://www.data.go.kr/data/15098547/openapi.do)
   - [한국토지주택공사_분양임대공고문 조회 서비스](https://www.data.go.kr/data/15058530/openapi.do)
   - 활용목적: "웹 사이트 개발", 내용: `개인 청약 일정 알림` · 첨부파일 없음 · 상세기능 전체 체크 · 라이선스 동의
3. **마이페이지 → 데이터활용 → Open API → 개발계정** → **인증키 복사(Decoding)**
   - 승인 직후 1~2시간은 "SERVICE KEY IS NOT REGISTERED"가 날 수 있어요(시간 지나면 해결).

### 3. Secrets 넣기 (내 저장소 → Settings → Secrets and variables → Actions → **New repository secret**)
Name은 **대문자·밑줄까지 똑같이**, Secret 칸에 값을 넣고 **Add secret**. 하나씩 반복하세요.

| Name | 넣을 값 | 필수 |
|---|---|---|
| `DATA_GO_KR_KEY` | 2번에서 복사한 인증키 | ✅ |
| `APP_PASSWORD` | 앱 열 때 쓸 내 비밀번호 (영문 소문자+숫자 12자 이상 추천, 꼭 따로 메모) | ✅ |
| `AREAS` | 관심 동네, 쉼표로 구분 — 아래 예시 참고 | ✅ |
| `NTFY_TOPIC` | 알림 주제 이름 — 남이 못 맞힐 영문+숫자 (예: `cy-` 뒤에 아무 글자 20개) | 알림 원하면 |
| `PROFILE_JSON` | 내 청약 정보 — 6번에서 앱이 만들어 줘요 | 나중에 |

**`AREAS` 쓰는 법** — `시·도 시·군·구 [동/구]` 순서로, 쉼표로 구분:
```
서울 관악구 신림동, 서울 마포구, 경기 수원시 영통구, 인천 연수구
```
- 시·구 전체: `서울 마포구`, `경기 광명시` · 특정 동만: `서울 관악구 신림동` · 시 안의 구: `경기 성남시 분당구`
- 서울 구는 `양천구`처럼 구 이름만 써도 돼요.

### 4. 앱 주소 켜기
내 저장소 → **Settings → Pages → Build and deployment → Source: `GitHub Actions`** 선택 (저장 버튼 없음)

### 5. 첫 실행
내 저장소 → **Actions** 탭 → (활성화 버튼이 보이면 눌러 주세요) → 왼쪽 **매일 청약 확인** → **Run workflow → Run workflow**
1~2분 뒤 초록 체크가 뜨면 앱 주소가 열려요:
`https://<내 GitHub 아이디>.github.io/<저장소 이름>/`

### 6. 휴대폰에 설치 + 내 정보 넣기
- **아이폰**: Safari로 앱 주소 → 비밀번호 → 아래 **공유(□↑) → 홈 화면에 추가**
- **안드로이드**: Chrome → 비밀번호 → **앱 설치** (또는 ⋮ → 홈 화면에 추가)
- 앱 **우리정보** 탭: 사는 곳(시·구·**사는 동**), 결혼 여부, 청약통장(가입일·납입 횟수·잔액), 월 소득, 세대주 여부 입력
  → **[이 휴대폰에 저장]** (바로 다시 판정) → **[JSON 복사]** → Secrets에 `PROFILE_JSON`으로 붙여넣기 (매일 알림 판정에도 반영)

### 7. 알림 받기 (ntfy, 무료)
휴대폰에 **ntfy** 앱 설치 ([아이폰](https://apps.apple.com/app/ntfy/id1625396347) · [안드로이드](https://play.google.com/store/apps/details?id=io.heckel.ntfy)) → **+** → `NTFY_TOPIC`에 넣은 값 그대로 → Subscribe
- 새 공고, 특별공급·1순위·접수·당첨발표 **전날과 당일**에 알림. 첫 실행 땐 "연결됐어요" 1건만.
- 주제 이름을 아는 사람은 알림을 볼 수 있으니 길고 무작위로. 알림엔 공고 이름만 들어가요.

### 자주 묻는 것
- **비밀번호 바꾸기**: Secrets의 `APP_PASSWORD` 연필(✏️) → 새 값 → Update → Actions에서 Run workflow. 휴대폰에서 새 비밀번호로 다시 열면 돼요(알림 기록만 초기화).
- **동네 바꾸기**: 앱 우리정보 탭 "관심 동네"에서 고치고 JSON 복사 → `PROFILE_JSON` 업데이트 (`AREAS`보다 우선). 빼는 건 휴대폰에 바로 반영.
- **원본이 업데이트되면?** 템플릿 복사본은 자동으로 따라오지 않아요. 새 기능이 필요하면 원본을 만든 사람에게 물어보세요.

## 🔒 어떻게 "나만" 보나요?

- 앱 주소는 누구나 열 수는 있지만, 안의 데이터는 **AES-256 암호화**(비밀번호 → PBKDF2 60만 회)라 **비밀번호 없이는 아무것도 안 보입니다.** 검색엔진 노출도 차단.
- 내 정보(통장·소득·관심 동네·사는 동)는 저장소 코드에 없고 **GitHub Secrets**와 암호화된 앱 데이터에만 있어요. 공개 저장소여도 Secrets는 소유자만 봅니다.
- 실행 로그(공개)에는 건수만 찍히고 동네 이름·개인정보는 출력하지 않습니다.
- 알림 기록·지도 좌표 캐시(`state/state.enc.json`)도 같은 비밀번호로 암호화돼요.

## 🗂️ 파일 구조

```
.github/workflows/daily.yml   매일 2회 실행 + Pages 배포
scripts/sources.mjs           청약홈·LH API 수집
scripts/build.mjs             동네 필터 → 판정 → 알림 → 암호화 → dist/ 생성
scripts/geocode.mjs           주소 → 지도 좌표 (Nominatim + 동/구 중심)
scripts/crypto.mjs            AES-GCM 암호화
site/engine.js                자격 판정 엔진·동네 해석 (앱·서버 공용)
site/app.js, index.html ...   휴대폰 앱(PWA, 지도는 Leaflet + OpenStreetMap)
fixtures/notices.json         테스트용 가짜 공고
```

로컬 테스트: `PROFILE_JSON="$(cat profile.example.json)" MOCK=1 node scripts/build.mjs` → `dist/` (비밀번호 `demo-1234`)
